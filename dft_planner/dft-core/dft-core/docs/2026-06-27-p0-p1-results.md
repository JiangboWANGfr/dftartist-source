# hdl-core 验证结果(P0–P3)

`hdl`(C++ / slang v10.0.101)对比 Python oracle(pyslang 11.0.0):
`dump_hierarchy.py` 和 `hierarchy_daemon.py`。

## P0 地基

slang 链接(`find_package` 预编译静态库)、`hdl --version`、`hdl selftest` 编译 RTL 打印 top —— 通过。

## Hierarchyshower 真实测试套件在 C++ 引擎上(`HDL_ENGINE=…/hdl`)

| 测试 | 结果 |
| --- | --- |
| blackbox(UnknownModule→黑盒) | ✅ |

| paramPorts(参数化 per-instance 宽度 + overrides) | ✅ |
| trace-fanin / trace-fanout | ✅ |

**全 5 绿;Python 默认路径不受影响(仍 3/3)。**

## 关键结论

- **C++ 引擎是 Python daemon 的逐字节 drop-in** —— 所有方法、两个真实设计、ready 事件全一致。
- **~25× 性能**(openc910)。
- 版本偏差(pyslang11 / slang10)对 hierarchy / ports / trace 结构零影响。
- `AnalysisManager.analyze` 无需 `freeze()`(对齐 pyslang),不影响后续懒展开。
