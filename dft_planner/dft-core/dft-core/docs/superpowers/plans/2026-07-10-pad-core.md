**Goal:** 新库 `pad-core`：解析 cell library（全部 model）→ 从网表抽出 pad 实例（黑盒、大小写敏感）→ gpio 上溯到顶层 port → 可编辑配置表（overlay）→ 生成 Tessent 边界扫描配置两段（`read_config_data` / `set_boundary_scan_port_options`），CLI + NDJSON 输出。

**Architecture:** 与 ctrlgen-core/drc-core 同型：静态库 `padcore`（链 `hdlcore`，slang 经其传递）+ 可执行 `pad`。celllib 解析是自研 tokenizer（无依赖）；网表侧复用 hdl-core 的 `parseFilelist`/`compileSingleTree`/`collectChildren`/`connNet`，pad 黑盒连接用 slang `UninstantiatedDefSymbol::getPortNames()/getPortConnections()` 新读（不改 hdl-core 任何现有代码）。

**Tech Stack:** C++20、slang v10（vendored）、hdl-core 的 `json/JsonValue.h`+`json/JsonWriter.h`、CMake+ctest、assert 风格单测 + 字节精确 golden（参照 `test_ctrlgen_gen.cpp` / `ctrlgen_golden.sh`）。

**Spec:** `docs/superpowers/specs/2026-07-10-pad-core-design.md`（§ 引用指它）。

**hdl-core 关键 API**（pad-core 消费，不修改）：

- `hdl::service::parseFilelist(path, {}, {})` → `FilelistResult{files, defines, incdirs}`（`hdl-core/service/Filelist.h:18`）
- `hdl::frontend::compileSingleTree(files, defines, incdirs, parseErr)` → `unique_ptr<Design>`，`design->comp` 是 `slang::ast::Compilation`（`hdl-core/frontend/SlangCompile.h:35`；用法示例 `app/cli_main.cpp:56-63`）
- 顶层：`design->comp->getRoot().topInstances`（`const InstanceSymbol*` 序列）
- 子级展开：`hdl::service::collectChildren(inst.body, kids)`；真实例判定 `isRealInstance`；叶名 `leafName`（`hdl-core/service/SlangHelpers.h`）
- pad 是**黑盒**：`SymbolKind::UninstantiatedDef` → `UninstantiatedDefSymbol`，有 `definitionName`、`getPortNames()`（具名连接的 pin 名，positional 为 ""）、`getPortConnections()`（`span<const AssertionExpr* const>`，与 names 按下标对应）。表达式包在 `SimpleAssertionExpr.expr` 里（`kind == AssertionExprKind::Simple`；`ae->bad()` 判 Invalid）。头文件：`slang/ast/symbols/InstanceSymbols.h`、`slang/ast/expressions/AssertionExpr.h`
- 表达式→网名：`ExpressionKind::NamedValue` → `e.getSymbolReference()->name`；常量位选 `ExpressionKind::ElementSelect` → `ElementSelectExpression.value()/selector()`，`selector().constant` 是 `const ConstantValue*`（绑定时常量折叠已填；若为空放弃）。头文件：`slang/ast/Expression.h`、`slang/ast/expressions/SelectExpressions.h`
- **真实例**的连接遍历（gpio 上溯用）照抄 `hdl-core/service/Netlist.cpp:84-103` 模式：`ci.getPortConnections()` → `pc->port`（`kind==SymbolKind::Port` → `as<PortSymbol>()`，有 `.name`/`.direction`）→ 绑定网 `hdl::service::connNet(pc)`（返回 `const Symbol*`，空 = 复合/悬空）
- JSON 进：`hdl::json::parse(text)` → `Value`（`find`/`str`/`.obj`/`.arr`，`hdl-core/json/JsonValue.h`）；JSON 出：`hdl::json::JsonWriter`（`hdl-core/json/JsonWriter.h`）

**重要语义**（来自 spec，写代码时不要跑偏）：

1. pad 判定只认 lib 属性：`cell_type = pad` 圈定 cell；`pad_from_io`→in / `pad_to_io`→out / `pad_pad_io`→inout（该 pin 即外部脚 padPin）；`pad_from_pad`→coreOutPin / `pad_to_pad`→coreInPin；`pad_enable_high|low`→enablePin+极性；`pad_pull0|1`→pull。
2. 网表匹配**大小写敏感精确**；只差大小写 → warning，不当 pad。
3. 输出 A 只放 `reuse` 已指派 且 `func!="ssn"` 且 gpio 已解析 的行；chip→`BoundaryScan`+`internal`，phy/sub→`EmbeddedBoundaryScan`+用户选 `external|internal`。
4. 输出 B：`-pad_io_ports` = 全部 pad 的 gpio（每行 8 个，续行 `\`，行首 3 空格，末名后紧跟 `}`）；`dont_touch` 行 = `bscan_en=yes` 的 gpio；无注释行。
5. `func`/`enable` P1 只存不生成；ssn 位宽 = 该有效方向（inout 取 reuse，否则 dir）上 func==ssn 的行数。

```cpp
#pragma once
// pad-core data model (spec: docs/superpowers/specs/2026-07-10-pad-core-design.md)
#include <string>
#include <vector>

namespace pad {

// ---- cell library (spec §5) ----
struct CellPin {
    std::string name;
    std::string dir;                 // "in" | "out" | "inout" | "" (undeclared)
    std::vector<std::string> attrs;  // mode() pin attributes, e.g. "pad_from_io"
};

struct CellDef {
    std::string name;      // module name, case preserved
    std::string cellType;  // cell_type value: "pad" / "and" / ...
    std::vector<CellPin> pins;
};

struct CellLib {
    std::vector<CellDef> cells;
    const CellDef* find(const std::string& name) const {
        for (const auto& c : cells)
            if (c.name == name) return &c;
        return nullptr;
    }
};

// pad cell roles derived from standard pin attributes (spec §5)
struct PadCellInfo {
    std::string cell;
    std::string dir;             // "in" | "out" | "inout"
    std::string padPin;          // pin carrying pad_from_io/pad_to_io/pad_pad_io
    std::string coreInPin;       // pad_to_pad ("" if none)
    std::string coreOutPin;      // pad_from_pad ("" if none)
    std::string enablePin;       // pad_enable_high/low ("" if none)
    std::string enablePolarity;  // "high" | "low" | ""
    std::string pull;            // "" | "pull0" | "pull1"
};

// ---- extracted pad instance = one config-table row (spec §7/§14) ----
struct PadInstance {
    std::string path;   // hierarchical path, unique key (dot-separated)
    std::string cell;
    std::string gpio;   // resolved top-level port ("" if unresolved)
    std::string dir;    // in | out | inout (from lib)
    std::string padNet;
    std::string coreInNet;
    std::string coreOutNet;
    std::string autoEnableNet;
    // manual columns (overlay, spec §7)
    bool bscanEn = false;
    std::string reuse;   // "" | "in" | "out" (inout only)
    std::string func;    // "" | "ssn" | free text
    std::string enable;  // defaults to autoEnableNet
};

struct ExtractResult {
    std::vector<PadInstance> pads;      // DFS pre-order
    std::vector<std::string> warnings;  // case-mismatch / unresolved gpio / ...
};

// ---- generation options (spec §8) ----
struct GenOptions {
    std::string level;  // "chip" | "phy" | "sub"
    std::string aux;    // "external" | "internal" (phy/sub only)
};

}  // namespace pad
```

- [x] **Step 7: 实现 `pad-core/celllib.cpp`**

```cpp
#include "celllib.h"

#include <cctype>
#include <stdexcept>

namespace pad {

namespace {

[[noreturn]] void fail(const std::string& why) { throw std::runtime_error("celllib: " + why); }

// ---- tokenizer: idents + single punct chars; skips ws and // and /* */ comments ----
struct Lexer {
    const std::string& t;
    size_t p = 0;
    explicit Lexer(const std::string& text) : t(text) {}

    void skipWs() {
        while (p < t.size()) {
            char c = t[p];
            if (std::isspace(static_cast<unsigned char>(c))) { ++p; continue; }
            if (c == '/' && p + 1 < t.size() && t[p + 1] == '/') {
                while (p < t.size() && t[p] != '\n') ++p;
                continue;
            }
            if (c == '/' && p + 1 < t.size() && t[p + 1] == '*') {
                p += 2;
                while (p + 1 < t.size() && !(t[p] == '*' && t[p + 1] == '/')) ++p;
                p = (p + 1 < t.size()) ? p + 2 : t.size();
                continue;
            }
            break;
        }
    }
    static bool identChar(char c) {
        return std::isalnum(static_cast<unsigned char>(c)) || c == '_' || c == '.' ||
               c == '[' || c == ']' || c == '"';
    }
    std::string next() {  // "" at end of input
        skipWs();
        if (p >= t.size()) return "";
        char c = t[p];
        if (identChar(c)) {
            size_t s = p;
            while (p < t.size() && identChar(t[p])) ++p;
            return t.substr(s, p - s);
        }
        ++p;
        return std::string(1, c);
    }
    std::string peek() {
        size_t save = p;
        std::string tok = next();
        p = save;
        return tok;
    }
};

// skip a balanced (...) block; opening '(' already consumed
void skipBalanced(Lexer& lx) {
    int depth = 1;
    while (depth > 0) {
        std::string tok = lx.next();
        if (tok.empty()) fail("unexpected EOF in (...) block");
        if (tok == "(") ++depth;
        else if (tok == ")") --depth;
    }
}

void skipToSemi(Lexer& lx) {
    while (true) {
        std::string tok = lx.next();
        if (tok.empty() || tok == ";") return;
        if (tok == "(") skipBalanced(lx);  // defensive
    }
}

CellPin* findPin(CellDef& d, const std::string& name) {
    for (auto& pin : d.pins)
        if (pin.name == name) return &pin;
    return nullptr;
}
CellPin& getPin(CellDef& d, const std::string& name) {
    if (CellPin* pin = findPin(d, name)) return *pin;
    d.pins.push_back(CellPin{name, "", {}});
    return d.pins.back();
}

// mode( pin (NAME) (attr; attr = v; ...) ... ) — opening '(' of mode already consumed
void parseMode(Lexer& lx, CellDef& d) {
    while (true) {
        std::string tok = lx.next();
        if (tok.empty()) fail(d.name + ": unexpected EOF in mode()");
        if (tok == ")") return;
        if (tok != "pin") {
            if (tok == "(") skipBalanced(lx);
            continue;
        }
        if (lx.next() != "(") fail(d.name + ": expected '(' after pin");
        std::string pname = lx.next();
        if (lx.next() != ")") fail(d.name + ": expected ')' after pin name");
        if (lx.next() != "(") fail(d.name + ": expected attr block after pin (" + pname + ")");
        CellPin& pin = getPin(d, pname);
        while (true) {
            std::string a = lx.next();
            if (a.empty()) fail(d.name + ": unexpected EOF in pin attrs");
            if (a == ")") break;
            if (a == ";") continue;
            pin.attrs.push_back(a);
            if (lx.peek() == "=") skipToSemi(lx);  // attr = value ...;
        }
    }
}

// model NAME (ports) ( body )
CellDef parseModel(Lexer& lx) {
    CellDef d;
    d.name = lx.next();
    if (d.name.empty() || d.name == "(") fail("model missing name");
    if (lx.next() != "(") fail(d.name + ": expected port list");
    while (true) {
        std::string tok = lx.next();
        if (tok.empty()) fail(d.name + ": unexpected EOF in port list");
        if (tok == ")") break;
        if (tok == ",") continue;
        d.pins.push_back(CellPin{tok, "", {}});
    }
    if (lx.next() != "(") fail(d.name + ": expected model body");
    while (true) {
        std::string tok = lx.next();
        if (tok.empty()) fail(d.name + ": unexpected EOF in model body");
        if (tok == ")") break;  // end of model
        if (tok == "cell_type") {
            if (lx.next() != "=") fail(d.name + ": expected '=' after cell_type");
            d.cellType = lx.next();
            skipToSemi(lx);
        } else if (tok == "mode") {
            if (lx.next() != "(") fail(d.name + ": expected '(' after mode");
            parseMode(lx, d);
        } else if (tok == "input" || tok == "output" || tok == "inout") {
            std::string dir = tok == "input" ? "in" : tok == "output" ? "out" : "inout";
            if (lx.next() != "(") fail(d.name + ": expected '(' after " + tok);
            while (true) {
                std::string n = lx.next();
                if (n.empty()) fail(d.name + ": unexpected EOF in " + tok + " list");
                if (n == ")") break;
                if (n == ",") continue;
                getPin(d, n).dir = dir;
            }
            if (lx.peek() == "(") {  // optional per-pin attr block: input (v) ( unused; ... )
                lx.next();
                skipBalanced(lx);
            }
        } else if (tok == "(") {
            skipBalanced(lx);  // structure block (instances / primitives)
        } else {
            if (lx.peek() == "=") skipToSemi(lx);  // key = value;  (else: stray ';' etc, ignore)
        }
    }
    return d;
}

}  // namespace

CellLib parseCellLib(const std::string& text) {
    CellLib lib;
    Lexer lx(text);
    while (true) {
        std::string tok = lx.next();
        if (tok.empty()) break;
        if (tok == "model") {
            lib.cells.push_back(parseModel(lx));
        } else if (tok == "(") {
            skipBalanced(lx);  // dft_cell_selection ( name ) ( ... ) etc.
        } else if (lx.peek() == "=") {
            skipToSemi(lx);  // library_format_version = 9;
        }
    }
    return lib;
}

std::map<std::string, PadCellInfo> buildPadDict(const CellLib& lib) {
    std::map<std::string, PadCellInfo> dict;
    for (const CellDef& c : lib.cells) {
        if (c.cellType != "pad") continue;
        PadCellInfo info;
        info.cell = c.name;
        for (const CellPin& p : c.pins) {
            for (const std::string& a : p.attrs) {
                if (a == "pad_from_io") { info.dir = "in"; info.padPin = p.name; }
                else if (a == "pad_to_io") { info.dir = "out"; info.padPin = p.name; }
                else if (a == "pad_pad_io") { info.dir = "inout"; info.padPin = p.name; }
                else if (a == "pad_from_pad") info.coreOutPin = p.name;
                else if (a == "pad_to_pad") info.coreInPin = p.name;
                else if (a == "pad_enable_high") { info.enablePin = p.name; info.enablePolarity = "high"; }
                else if (a == "pad_enable_low") { info.enablePin = p.name; info.enablePolarity = "low"; }
                else if (a == "pad_pull0") info.pull = "pull0";
                else if (a == "pad_pull1") info.pull = "pull1";
            }
        }
        if (info.dir.empty() || info.padPin.empty()) continue;  // malformed pad: skip (P1)
        dict.emplace(c.name, std::move(info));
    }
    return dict;
}

}  // namespace pad
```

```cpp
using SK = slang::ast::SymbolKind;

namespace pad {

namespace {

[[noreturn]] void fail(const std::string& why) { throw std::runtime_error("pad extract: " + why); }

std::string lower(std::string s) {
    std::transform(s.begin(), s.end(), s.begin(),
                   [](unsigned char c) { return static_cast<char>(std::tolower(c)); });
    return s;
}

// bound expression -> net name: identifier "n"; constant bit-select "n[i]"; else ""
std::string exprNet(const Expression& e) {
    if (e.kind == ExpressionKind::NamedValue) {
        const Symbol* s = e.getSymbolReference();
        return s ? std::string(s->name) : "";
    }
    if (e.kind == ExpressionKind::ElementSelect) {
        const auto& sel = e.as<ElementSelectExpression>();
        std::string base = exprNet(sel.value());
        if (base.empty() || base.find('[') != std::string::npos) return "";
        const slang::ConstantValue* cv = sel.selector().constant;  // folded at bind time
        if (cv && cv->isInteger()) {
            if (auto iv = cv->integer().as<int64_t>())
                return base + "[" + std::to_string(*iv) + "]";
        }
        return "";
    }
    return "";  // concat / tie / anything composite
}

// blackbox instance pin -> net (named connections only; "" for empty/tie/composite)
std::vector<std::pair<std::string, std::string>> bboxConns(const UninstantiatedDefSymbol& u) {
    std::vector<std::pair<std::string, std::string>> out;
    auto names = u.getPortNames();
    auto conns = u.getPortConnections();
    for (size_t i = 0; i < names.size(); ++i) {
        std::string net;
        if (i < conns.size() && conns[i] && !conns[i]->bad() &&
            conns[i]->kind == AssertionExprKind::Simple)
            net = exprNet(conns[i]->as<SimpleAssertionExpr>().expr);
        out.emplace_back(std::string(names[i]), net);
    }
    return out;
}

struct Walker {
    const std::map<std::string, PadCellInfo>& dict;
    ExtractResult& res;

    void addPad(const UninstantiatedDefSymbol& u, const PadCellInfo& info,
                const std::string& path) {
        PadInstance row;
        row.path = path;
        row.cell = info.cell;
        row.dir = info.dir;
        for (auto& [pin, net] : bboxConns(u)) {
            if (pin == info.padPin) row.padNet = net;
            else if (!info.coreInPin.empty() && pin == info.coreInPin) row.coreInNet = net;
            else if (!info.coreOutPin.empty() && pin == info.coreOutPin) row.coreOutNet = net;
            else if (!info.enablePin.empty() && pin == info.enablePin) row.autoEnableNet = net;
        }
        row.enable = row.autoEnableNet;  // default; overlay may override (spec §12)
        res.pads.push_back(std::move(row));
    }

    void checkCaseMismatch(const std::string& cellName, const std::string& path) {
        std::string lc = lower(cellName);
        for (const auto& [name, info] : dict) {
            if (name != cellName && lower(name) == lc) {
                res.warnings.push_back(path + ": module '" + cellName + "' resembles pad cell '" +
                                       name + "' (case mismatch), not treated as pad");
                return;
            }
        }
    }

    void walk(const InstanceSymbol& inst, const std::string& path) {
        std::vector<const Symbol*> kids;
        hdl::service::collectChildren(inst.body, kids);
        for (const Symbol* k : kids) {
            std::string kpath = path + "." + hdl::service::leafName(*k);
            if (k->kind == SK::UninstantiatedDef) {
                const auto& u = k->as<UninstantiatedDefSymbol>();
                std::string cellName(u.definitionName);
                auto it = dict.find(cellName);
                if (it != dict.end()) addPad(u, it->second, kpath);
                else checkCaseMismatch(cellName, kpath);
            } else if (hdl::service::isRealInstance(*k)) {
                walk(k->as<InstanceSymbol>(), kpath);
            }
        }
    }
};

}  // namespace

ExtractResult extractPads(const std::string& filelistPath, const CellLib& lib) {
    auto fl = hdl::service::parseFilelist(filelistPath, {}, {});
    if (fl.files.empty()) fail("no source files resolved from " + filelistPath);
    std::string parseErr;
    auto design = hdl::frontend::compileSingleTree(fl.files, fl.defines, fl.incdirs, parseErr);
    if (!design) fail("parse error: " + parseErr);

    ExtractResult res;
    auto dict = buildPadDict(lib);
    Walker w{dict, res};
    for (auto* top : design->comp->getRoot().topInstances)
        w.walk(*top, std::string(top->name));
    return res;
}

}  // namespace pad
```

```cpp
struct Walker {
    const std::map<std::string, PadCellInfo>& dict;
    ExtractResult& res;
    std::vector<const InstanceSymbol*> chain;  // top .. current enclosing instance

    // net name in chain.back()'s scope -> top-level port name ("" + warning if unresolved)
    std::string resolveGpio(std::string net, const std::string& padPath) {
        if (net.empty()) {
            res.warnings.push_back(padPath + ": pad pin unconnected/composite, gpio unresolved");
            return "";
        }
        if (net.find('[') != std::string::npos) {
            res.warnings.push_back(padPath + ": bit-select pad net '" + net +
                                   "' not traced (P1 limitation)");
            return "";
        }
        for (size_t level = chain.size(); level-- > 0;) {
            const InstanceSymbol* cur = chain[level];
            bool isPort = false;
            for (const Symbol* p : cur->body.getPortList())
                if (p->kind == SK::Port && p->as<PortSymbol>().name == net) { isPort = true; break; }
            if (!isPort) {
                res.warnings.push_back(padPath + ": net '" + net +
                                       "' is not a boundary port, gpio unresolved");
                return "";
            }
            if (level == 0) return net;  // reached top: net IS the top-level port
            const Symbol* outer = nullptr;
            for (auto* pc : cur->getPortConnections()) {  // parent-side bindings (Netlist.cpp:90)
                if (pc->port.kind == SK::Port && pc->port.name == net) {
                    outer = hdl::service::connNet(pc);
                    break;
                }
            }
            if (!outer) {
                res.warnings.push_back(padPath + ": port '" + net + "' unconnected at " +
                                       std::string(cur->name) + ", gpio unresolved");
                return "";
            }
            net = std::string(outer->name);
        }
        return "";
    }

    void addPad(const UninstantiatedDefSymbol& u, const PadCellInfo& info,
                const std::string& path) {
        PadInstance row;
        row.path = path;
        row.cell = info.cell;
        row.dir = info.dir;
        for (auto& [pin, net] : bboxConns(u)) {
            if (pin == info.padPin) row.padNet = net;
            else if (!info.coreInPin.empty() && pin == info.coreInPin) row.coreInNet = net;
            else if (!info.coreOutPin.empty() && pin == info.coreOutPin) row.coreOutNet = net;
            else if (!info.enablePin.empty() && pin == info.enablePin) row.autoEnableNet = net;
        }
        row.gpio = resolveGpio(row.padNet, path);
        row.enable = row.autoEnableNet;  // default; overlay may override (spec §12)
        res.pads.push_back(std::move(row));
    }

    void checkCaseMismatch(const std::string& cellName, const std::string& path) {
        std::string lc = lower(cellName);
        for (const auto& [name, info] : dict) {
            if (name != cellName && lower(name) == lc) {
                res.warnings.push_back(path + ": module '" + cellName + "' resembles pad cell '" +
                                       name + "' (case mismatch), not treated as pad");
                return;
            }
        }
    }

    void walk(const InstanceSymbol& inst, const std::string& path) {
        chain.push_back(&inst);
        std::vector<const Symbol*> kids;
        hdl::service::collectChildren(inst.body, kids);
        for (const Symbol* k : kids) {
            std::string kpath = path + "." + hdl::service::leafName(*k);

            } else if (hdl::service::isRealInstance(*k)) {

            }
        }

    }
```

```cpp
#include "table.h"

#include <stdexcept>

#include "json/JsonValue.h"  // header-only parser shared from hdl-core

namespace pad {

namespace {
using hdl::json::Value;

[[noreturn]] void fail(const std::string& why) { throw std::runtime_error("pad overlay: " + why); }

bool parseYesNo(const std::string& s, const std::string& path) {
    if (s == "yes" || s == "y") return true;
    if (s == "no" || s == "n") return false;
    fail(path + ": bscan_en must be yes|no");
}
}  // namespace

void applyOverlay(ExtractResult& r, const std::string& jsonText) {
    Value v = hdl::json::parse(jsonText);
    const Value* pads = v.find("pads");
    if (!pads || pads->type != Value::Type::Object) fail("missing 'pads' object");
    for (const auto& [path, cfg] : pads->obj) {
        PadInstance* row = nullptr;
        for (auto& p : r.pads)
            if (p.path == path) { row = &p; break; }
        if (!row) fail("unknown pad path '" + path + "'");
        if (cfg.type != Value::Type::Object) fail(path + ": entry must be an object");
        for (const auto& [k, val] : cfg.obj) {
            if (val.type != Value::Type::Str) fail(path + ": '" + k + "' must be a string");
            if (k == "bscan_en") {
                row->bscanEn = parseYesNo(val.s, path);
            } else if (k == "reuse") {
                if (val.s != "in" && val.s != "out") fail(path + ": reuse must be in|out");
                if (row->dir != "inout") fail(path + ": reuse only applies to inout pads");
                row->reuse = val.s;
            } else if (k == "func") {
                row->func = val.s;
            } else if (k == "enable") {
                row->enable = val.s;
            } else {
                fail(path + ": unknown key '" + k + "'");
            }
        }
        if (row->func == "ssn" && row->dir == "inout" && row->reuse.empty())
            fail(path + ": func=ssn on an inout pad requires reuse");
    }
}

SsnSummary ssnSummary(const std::vector<PadInstance>& rows) {
    SsnSummary s;
    for (const auto& r : rows) {
        if (r.func != "ssn") continue;
        std::string eff = r.dir == "inout" ? r.reuse : r.dir;
        if (eff == "in") ++s.inWidth;
        else if (eff == "out") ++s.outWidth;
    }
    return s;
}

}  // namespace pad
```

```cpp
#include "gen.h"

#include <algorithm>
#include <sstream>
#include <stdexcept>

namespace pad {

namespace {

[[noreturn]] void fail(const std::string& why) { throw std::runtime_error("pad gen: " + why); }

std::string join(const std::vector<std::string>& v, const std::string& sep) {
    std::string out;
    for (size_t i = 0; i < v.size(); ++i) {
        if (i) out += sep;
        out += v[i];
    }
    return out;
}

}  // namespace

std::string generateAuxPorts(const std::vector<PadInstance>& rows, const GenOptions& opts) {
    std::string wrapper, cat;
    if (opts.level == "chip") {
        wrapper = "BoundaryScan";
        cat = "internal";
    } else if (opts.level == "phy" || opts.level == "sub") {
        wrapper = "EmbeddedBoundaryScan";
        if (opts.aux != "external" && opts.aux != "internal")
            fail("level " + opts.level + " requires --aux external|internal");
        cat = opts.aux;
    } else {
        fail("level must be chip|phy|sub");
    }

    std::vector<std::string> ins, outs;
    for (const auto& r : rows) {
        if (r.reuse.empty() || r.func == "ssn" || r.gpio.empty()) continue;  // spec §9
        (r.reuse == "in" ? ins : outs).push_back(r.gpio);
    }
    if (ins.empty() && outs.empty()) return "";

    std::ostringstream o;
    o << "read_config_data -in_wrapper $dftspec/" << wrapper << " -rep -from_string {\n";
    o << "   AuxiliaryInputOutputPorts {\n";
    if (!ins.empty())
        o << "     " << cat << "_auxiliary_input_ports : " << join(ins, ", ") << ";\n";
    if (!outs.empty())
        o << "     " << cat << "_auxiliary_output_ports : " << join(outs, ", ") << ";\n";
    o << "   }\n";
    o << " }\n";
    return o.str();
}

std::string generatePortOptions(const std::vector<PadInstance>& rows) {
    std::vector<std::string> all, dt;
    for (const auto& r : rows) {
        if (r.gpio.empty()) continue;
        all.push_back(r.gpio);
        if (r.bscanEn) dt.push_back(r.gpio);
    }
    if (all.empty()) return "";

    std::ostringstream o;
    o << "set_boundary_scan_port_options -pad_io_ports { \\\n";
    for (size_t i = 0; i < all.size(); i += 8) {
        size_t end = std::min(all.size(), i + 8);
        o << "   " << join({all.begin() + static_cast<long>(i), all.begin() + static_cast<long>(end)}, " ");
        o << (end == all.size() ? "}\n" : " \\\n");
    }
    if (!dt.empty())
        o << "set_boundary_scan_port_options [get_ports [list " << join(dt, " ")
          << "]] -cell_options dont_touch\n";
    return o.str();
}

}  // namespace pad
```

```cpp
#include "extract.h"

std::string readFile(const std::string& p, bool& ok) {
    std::ifstream in(p);
    ok = in.good();
    std::stringstream ss;
    ss << in.rdbuf();
    return ss.str();
}

struct Args {
    std::string cmd, filelist, lib, config, level, aux;
    bool json = false;
};

bool parseArgs(int argc, char** argv, Args& a) {
    if (argc < 2) return false;
    a.cmd = argv[1];
    for (int i = 2; i < argc; ++i) {
        std::string_view s = argv[i];
        auto val = [&](std::string& dst) {
            if (i + 1 >= argc) return false;
            dst = argv[++i];
            return true;
        };
        if (s == "-f") { if (!val(a.filelist)) return false; }
        else if (s == "--lib") { if (!val(a.lib)) return false; }
        else if (s == "--config") { if (!val(a.config)) return false; }
        else if (s == "--level") { if (!val(a.level)) return false; }
        else if (s == "--aux") { if (!val(a.aux)) return false; }
        else if (s == "--json") a.json = true;
        else return false;
    }
    return true;
}

pad::ExtractResult loadTable(const Args& a) {
    bool ok = false;
    std::string libText = readFile(a.lib, ok);
    if (!ok) throw std::runtime_error("cannot read lib: " + a.lib);
    pad::CellLib lib = pad::parseCellLib(libText);
    pad::ExtractResult r = pad::extractPads(a.filelist, lib);
    if (!a.config.empty()) {
        std::string cfg = readFile(a.config, ok);
        if (!ok) throw std::runtime_error("cannot read config: " + a.config);
        pad::applyOverlay(r, cfg);
    }
    return r;
}

void writeTableJson(const pad::ExtractResult& r, hdl::json::JsonWriter& w) {
    w.beginObject();
    w.key("pads");
    w.beginArray();
    for (const auto& p : r.pads) {
        w.beginObject();
        w.key("path"); w.value(p.path);
        w.key("gpio"); w.value(p.gpio);
        w.key("cell"); w.value(p.cell);
        w.key("dir"); w.value(p.dir);
        w.key("padNet"); w.value(p.padNet);
        w.key("coreInNet"); w.value(p.coreInNet);
        w.key("coreOutNet"); w.value(p.coreOutNet);
        w.key("autoEnableNet"); w.value(p.autoEnableNet);
        w.key("bscanEn"); w.value(p.bscanEn);
        w.key("reuse"); w.value(p.reuse);
        w.key("func"); w.value(p.func);
        w.key("enable"); w.value(p.enable);
        w.endObject();
    }
    w.endArray();
    pad::SsnSummary ssn = pad::ssnSummary(r.pads);
    w.key("ssn");
    w.beginObject();
    w.key("inWidth"); w.value(ssn.inWidth);
    w.key("outWidth"); w.value(ssn.outWidth);
    w.endObject();
    w.key("warnings");
    w.beginArray();
    for (const auto& s : r.warnings) w.value(s);
    w.endArray();
    w.endObject();
}

    pad::ExtractResult r = loadTable(a);
    if (a.json) {
        hdl::json::JsonWriter w;
        writeTableJson(r, w);
        std::printf("%s\n", w.str().c_str());
        return 0;
    }
    std::printf("path\tgpio\tpad\tdir\tbscan_en\treuse\tfunc\tenable\n");
    for (const auto& p : r.pads)
        std::printf("%s\t%s\t%s\t%s\t%s\t%s\t%s\t%s\n", p.path.c_str(), p.gpio.c_str(),
                    p.cell.c_str(), p.dir.c_str(), p.bscanEn ? "y" : "n", p.reuse.c_str(),
                    p.func.c_str(), p.enable.c_str());
    for (const auto& s : r.warnings) std::fprintf(stderr, "WARN %s\n", s.c_str());
    return 0;
}

int cmdGen(const Args& a) {
    pad::ExtractResult r = loadTable(a);
    pad::GenOptions opts{a.level, a.aux};
    std::string outA = pad::generateAuxPorts(r.pads, opts);
    std::string outB = pad::generatePortOptions(r.pads);
    if (!outA.empty()) std::fputs(outA.c_str(), stdout);
    if (!outA.empty() && !outB.empty()) std::fputs("\n", stdout);
    if (!outB.empty()) std::fputs(outB.c_str(), stdout);
    for (const auto& s : r.warnings) std::fprintf(stderr, "WARN %s\n", s.c_str());
    return 0;
}

}  // namespace

int main(int argc, char** argv) {
    Args a;
    if (!parseArgs(argc, argv, a)) {
        std::fprintf(stderr,
                     "usage: pad table -f <filelist> --lib <celllib> [--config <overlay.json>] [--json]\n"
                     "       pad gen   -f <filelist> --lib <celllib> [--config <overlay.json>]"
                     " --level chip|phy|sub [--aux external|internal]\n");

    }
    try {
        if (a.cmd == "table") return cmdTable(a);
        if (a.cmd == "gen") return cmdGen(a);
    } catch (const std::exception& e) {

        return 2;
    }
    std::fprintf(stderr, "pad: unknown command '%s'\n", a.cmd.c_str());
    return 2;
}
```

```cpp
// NDJSON loop: {"id":N,"method":"pad.table"|"pad.generate","params":{...}} per line.
// params: filelist, lib (paths); config (INLINE overlay JSON text, optional);
//         level, aux (pad.generate only).
int cmdServe() {
    std::string line;
    while (std::getline(std::cin, line)) {
        if (line.empty()) continue;
        std::string id = "null", out;
        try {
            hdl::json::Value req = hdl::json::parse(line);
            if (const auto* idv = req.find("id")) {
                if (idv->type == hdl::json::Value::Type::Int) id = std::to_string(idv->i);
                else if (idv->type == hdl::json::Value::Type::Str) id = "\"" + idv->s + "\"";
            }
            std::string method = req.str("method");
            const auto* params = req.find("params");
            if (!params) throw std::runtime_error("missing params");

            Args a;
            a.filelist = params->str("filelist");
            a.lib = params->str("lib");
            a.level = params->str("level");
            a.aux = params->str("aux");
            std::string cfgText = params->str("config");

            bool ok = false;
            std::string libText = readFile(a.lib, ok);
            if (!ok) throw std::runtime_error("cannot read lib: " + a.lib);
            pad::CellLib lib = pad::parseCellLib(libText);
            pad::ExtractResult r = pad::extractPads(a.filelist, lib);
            if (!cfgText.empty()) pad::applyOverlay(r, cfgText);

            hdl::json::JsonWriter w;
            if (method == "pad.table") {
                writeTableJson(r, w);
            } else if (method == "pad.generate") {
                pad::GenOptions opts{a.level, a.aux};
                w.beginObject();
                w.key("outputA"); w.value(pad::generateAuxPorts(r.pads, opts));
                w.key("outputB"); w.value(pad::generatePortOptions(r.pads));
                w.endObject();
            } else {
                throw std::runtime_error("unknown method: " + method);
            }
            out = "{\"id\":" + id + ",\"result\":" + w.str() + "}";
        } catch (const std::exception& e) {
            hdl::json::JsonWriter w;
            w.value(std::string(e.what()));
            out = "{\"id\":" + id + ",\"error\":" + w.str() + "}";
        }
        std::printf("%s\n", out.c_str());
        std::fflush(stdout);
    }
    return 0;
}
```
